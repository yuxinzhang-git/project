# A 股行情看板实时数据设计

## 状态

用户已批准设计。行情源采用东方财富公开接口；该接口未承诺服务等级，不视为交易所授权或毫秒级实时行情。

## 目标

把 `frontend/stock.html` 当前硬编码的行情、走势和组合表现替换为可核验的公开行情数据。页面必须区分盘中报价、定期财报字段、缓存数据和上游不可用状态，不能将静态示例标为实时数据。

## 数据源与边界

- 由 FastAPI 服务端请求东方财富公开行情接口，浏览器只调用本站 API。
- 服务端只允许当前看板中的十只 A 股和沪深 300 指数代码，不接受任意 URL 或任意证券代码。
- 报价包括上游实际提供的最新价、涨跌幅、昨收、开盘、最高、最低、成交量/额，以及可用时的 PE/PB。缺字段时返回空值，不用旧示例值补齐。
- ROE 若能从同一公开数据源取得，则返回最新可用财报值及报告期；它是定期披露数据，不标为实时。无可用值时显示“暂无”。
- 历史图表从公开日线数据生成，覆盖 6 个月和 1 年；不保留合成趋势数组。
- 页面报告本地抓取时间；只有上游提供并可验证更新时间时才展示上游时间。不得暗示数据具有实时 SLA。

## API 与数据流

- `GET /api/stocks/quotes` 返回固定自选股、沪深 300 报价、抓取时间及逐项可用性。
- `GET /api/stocks/{code}/history?period=6m|1y` 返回白名单股票的真实日线；代码和周期均须校验。
- 后端设置明确的连接/读取超时、响应状态和 JSON 结构校验；上游错误转换为可读的服务错误，不返回任意上游响应体。
- 报价使用 10 秒进程内缓存，历史日线使用 5 分钟缓存，ROE/财报数据使用 24 小时缓存，以避免重复请求放大上游负载。每份缓存保留获取时间；过期数据不可标成当前行情。
- 前端首次加载请求报价；仅当页面可见时每 15 秒刷新，手动刷新继续可用。选择股票或周期时加载相应日线。

## 页面行为

- 组合当日表现按十只股票等权计算；同时显示沪深 300 当日变化，最强标的按实时涨跌幅计算。
- 股票表和详情展示行情源实际返回的报价字段。PE/PB 仅在有数据时显示；ROE 标注报告期。
- 图表展示真实日线收盘价和日期，移除现有伪造基准线。
- 移除没有可核验输入依据的综合评分、六维评分、个股洞察和仓位建议。
- 成功刷新后显示抓取时间。刷新失败时保留本次页面会话中最近一次成功响应，并醒目标记其已过期及原抓取时间；首次加载失败时显示错误状态，不回退到样例数据。
- 非交易时段仍可展示数据源最近返回的报价，但标明其为最近报价，而非当前成交价。

## 验证

- 服务单元测试使用模拟 HTTP 响应，覆盖字段映射、单位换算、响应缺字段、非 JSON/上游错误和超时。
- API 测试覆盖报价、有效和无效股票代码、有效和无效周期，以及上游失败映射。
- 前端静态/行为测试确认不再包含硬编码价格或合成趋势，轮询只在页面可见时运行，失败状态不会被呈现为新数据。
- 运行项目 Python 测试与编译检查；真实源联调只有在当前环境网络可用时执行，未联调时不得声称供应商链路已验证。

## 非目标

- 不提供交易下单、买卖建议或投资组合风险分析。
- 不承诺免费公开源持续可用、无延迟或具有商业授权。
- 不新增行情供应商 API Key 或第三方 Python 依赖。
